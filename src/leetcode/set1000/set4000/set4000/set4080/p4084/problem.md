# 4084. 有向网格中的最后访问单元格

[Problem link](https://leetcode.cn/problems/last-visited-cell-in-a-directional-grid/description/)

给你一个 `m x n` 的矩阵 `grid`，其中每个单元格包含以下字符之一：

- `'L'`：向左移动一格。
- `'R'`：向右移动一格。
- `'U'`：向上移动一格。
- `'D'`：向下移动一格。

你从单元格 `(0, 0)` 出发，并将其视为已访问。每一步都按照当前单元格中的字符指示，移动到对应的单元格。

如果下一步移动会离开网格，或者进入一个已经访问过的单元格，则移动过程结束。在这两种情况下，该次移动都不会执行。

返回一个整数数组 `[r, c]`，表示最后一个访问的单元格的行下标和列下标。下标从 0 开始。

## Function signature

```go
func lastVisitedCell(grid [][]byte) []int
```

## Examples

### Example 1

```text
Input: grid = [["R","D"],["U","L"]]
Output: [1,0]
```

从单元格 `(0, 0)` 出发，其中的字符为 `'R'`，因此向右移动到 `(0, 1)`。在单元格 `(0, 1)` 中，字符为 `'D'`，因此向下移动到 `(1, 1)`。在单元格 `(1, 1)` 中，字符为 `'L'`，因此向左移动到 `(1, 0)`。在单元格 `(1, 0)` 中，字符为 `'U'`，表示应移动到 `(0, 0)`，但 `(0, 0)` 已经访问过，因此不会执行该次移动。移动过程结束于最后访问的单元格 `(1, 0)`。

### Example 2

```text
Input: grid = [["R","R","R"]]
Output: [0,2]
```

从单元格 `(0, 0)` 出发，其中的字符为 `'R'`，因此向右移动到 `(0, 1)`。在单元格 `(0, 1)` 中，字符为 `'R'`，因此向右移动到 `(0, 2)`。在单元格 `(0, 2)` 中，字符为 `'R'`，表示应移动到 `(0, 3)`，但 `(0, 3)` 位于网格之外，因此不会执行该次移动。移动过程结束于最后访问的单元格 `(0, 2)`。

## Constraints

- `1 <= m == grid.length <= 10^5`
- `1 <= n == grid[i].length <= 10^5`
- `m * n <= 10^5`
- `grid[i][j]` 为 `'L'`、`'R'`、`'U'` 或 `'D'` 之一
