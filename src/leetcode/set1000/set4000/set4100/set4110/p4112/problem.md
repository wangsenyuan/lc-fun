# 4112. 将子树置零后的最大得分

[Problem link](https://leetcode.cn/problems/maximize-score-after-zeroing-subtrees/description/)

给你一个长度为 `n` 的整数数组 `parent`，表示一棵节点编号从 0 到 `n - 1` 的有根树，其中 `parent[i]` 表示节点 `i` 的父节点。树的根节点为节点 0，因此 `parent[0] = -1`。

另给你两个长度均为 `n` 的整数数组 `op` 和 `score`，其中 `op[i]` 决定节点 `i` 允许执行的操作，`score[i]` 表示该节点的分数。

你需要按照以下规则处理每个非叶节点 `i`：

- 如果 `op[i] = 0`，你可以选择节点 `i` 的至多一个子节点，并将以该子节点为根的子树中所有节点的分数设为 0。
- 如果 `op[i] = 1`，你必须选择节点 `i` 的恰好一个子节点，并将以该子节点为根的子树中所有节点的分数设为 0。

每个非叶节点都必须恰好处理一次。你可以按任意顺序处理这些节点。

返回执行这些操作后，所有节点分数之和的最大可能值。

叶节点是没有子节点的节点。

以某个节点为根的子树由该节点及其所有后代节点组成。

## Function signature

```go
func maxScore(parent []int, op []int, score []int) int
```

## Examples

### Example 1

```text
Input: parent = [-1,0,0,0,1,2,3,3], op = [1,1,0,0,1,1,0,1], score = [5,6,1,2,3,2,3,-3]
Output: 16
```

一种最优方案是按以下顺序处理节点：

1. 节点 4、5、6 和 7：它们都是叶节点，因此不对它们执行任何操作。
2. 节点 1：由于 `op[1] = 1`，我们必须选择它的一个子节点。选择节点 4，将以它为根的子树中所有节点（节点 4）的分数设为 0。
3. 节点 2：由于 `op[2] = 0`，我们可以选择一个子节点，也可以不执行任何操作。对于该节点，我们不执行任何操作。
4. 节点 3：由于 `op[3] = 0`，我们可以选择一个子节点，也可以不执行任何操作。选择节点 7，将以它为根的子树中所有节点（节点 7）的分数设为 0。
5. 节点 0：由于 `op[0] = 1`，我们必须选择它的一个子节点。选择节点 2，将以它为根的子树中所有节点（节点 2 和 5）的分数设为 0。

执行这些操作后，各节点的分数为 `[5, 6, 0, 2, 0, 0, 3, 0]`，总和为 16。

不存在能够得到更大分数总和的合法操作序列。因此，答案为 16。

### Example 2

```text
Input: parent = [-1,0,0], op = [0,0,0], score = [1,2,3]
Output: 6
```

- 我们只需要处理节点 0，因为节点 1 和节点 2 都是叶节点。
- 由于 `op[0] = 0`，我们可以选择不执行任何操作。
- 因此，所有节点的分数都得以保留，得到的最大分数总和为 6。

### Example 3

```text
Input: parent = [-1], op = [1], score = [-10]
Output: -10
```

- 树中唯一的节点是叶节点，因此无法对任何节点执行操作。
- 因此，最大分数总和为 -10。

## Constraints

- `1 <= n <= 10^5`
- `n == parent.length == op.length == score.length`
- `parent[0] == -1`
- 对于所有 `i` 在 `[1, n - 1]` 范围内，均有 `0 <= parent[i] <= n - 1`
- `0 <= op[i] <= 1`
- `-10^4 <= score[i] <= 10^4`
- 输入保证数组 `parent` 表示一棵以节点 0 为根的合法树。
