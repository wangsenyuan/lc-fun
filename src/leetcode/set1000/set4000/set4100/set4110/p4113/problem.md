# 4113. 整除和博弈

[Problem link](https://leetcode.cn/problems/game-of-divisible-sums/description/)

Alice 和 Bob 正在用一个整数数组 `nums` 玩游戏。Alice 先手。

每个回合，当前玩家可以取走并移除最左边的一个元素，或者在至少还剩两个元素时，取走并移除最左边的两个元素。

本回合取走的元素之和决定接下来由谁行动：

- 如果该总和能被 3 整除，则接下来由另一位玩家行动。
- 否则，当前玩家继续行动。

一位玩家的得分是其取走的所有元素的值之和。

两位玩家都采用最优策略，各自力求最大化自己的得分。

当所有元素都被取走时，游戏结束。

返回 Alice 的得分减去 Bob 的得分。

## Function signature

```go
func maxDifference(nums []int) int64
```

## Examples

### Example 1

```text
Input: nums = [3,6,4]
Output: 5
```

一种最优的回合序列如下：

1. Alice 取走最左边的两个元素。它们的总和为 `3 + 6 = 9`，能被 3 整除，因此接下来由 Bob 行动。此时 Alice 的得分为 9，剩余数组为 `[4]`。
2. Bob 取走唯一剩余的元素。他的得分为 4，游戏结束。

Alice 的得分减去 Bob 的得分为 `9 - 4 = 5`，因此答案为 5。

### Example 2

```text
Input: nums = [6,1,2,1,2]
Output: 12
```

一种最优的回合序列如下：

1. Alice 取走最左边的两个元素。它们的总和为 `6 + 1 = 7`，不能被 3 整除，因此 Alice 继续行动。此时她的得分为 7，剩余数组为 `[2, 1, 2]`。
2. Alice 取走最左边的一个元素。它的值为 2，不能被 3 整除，因此 Alice 继续行动。此时她的得分为 `7 + 2 = 9`，剩余数组为 `[1, 2]`。
3. Alice 取走剩余的两个元素。此时她的得分为 `9 + 1 + 2 = 12`，游戏结束。

Bob 没有取走任何元素，因此他的得分为 0。Alice 的得分减去 Bob 的得分为 `12 - 0 = 12`，因此答案为 12。

### Example 3

```text
Input: nums = [3,3,4,5]
Output: -3
```

一种最优的回合序列如下：

1. Alice 取走最左边的两个元素。它们的总和为 `3 + 3 = 6`，能被 3 整除，因此接下来由 Bob 行动。此时 Alice 的得分为 6，剩余数组为 `[4, 5]`。
2. Bob 取走剩余的两个元素。他的得分为 `4 + 5 = 9`，游戏结束。

Alice 的得分减去 Bob 的得分为 `6 - 9 = -3`，因此答案为 -3。

## Constraints

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
